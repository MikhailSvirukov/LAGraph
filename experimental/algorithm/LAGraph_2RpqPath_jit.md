# Типы RPQ для JIT

Ветка `svmk17/rpq-paths-auto-optimized-jit-types` основана на оптимизированной
версии без профилирования `a05fb37a`. Оба умножения сохраняют режим AUTO.

H, C, P и два контекстных скаляра регистрируются через `GxB_Type_new` с C-именем
и определением. В H гибкий массив заменён в JIT-определении конкретным массивом
нужного размера. Размер входит в имя типа, поэтому автоматы разных размеров
в одном процессе не меняют определение одного и того же имени. Пустой массив
представляется только заголовком. C/P и скаляры содержат неизменные по размещению
поля и непрозрачные указатели: внутренние ядра копируют значения, владение
внешними блоками остаётся у запроса.

Эта версия требует патча GraphBLAS из ветки `svmk17/rpq-jit-select-types`:
select должен проверять пригодность типа матрицы к JIT и учитывать тип в ключе
кэша даже при встроенном операторе, который не читает значения (NONZOMBIE).
Без патча ядро может повторно использоваться для другого размера UDT.

Определения пользовательских операций пока не передаются: специализированные
JIT-ядра наших полукольцевых умножений этим изменением не включаются. Определения
типов позволяют безопасно компилировать внутренние операции над значениями.

`test_2RpqPath_jit` проверяет sizeof через компилятор JIT, удаление элементов
не-iso матриц, сохранность всех байтов и сохранение режима JIT_ON для всех пяти
типов и двух размеров автомата. Для отдельного пустого кэша можно задать
`LAGRAPH_TEST_JIT_CACHE`; это настройка только теста.
